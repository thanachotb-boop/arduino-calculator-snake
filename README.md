# 🧮 Arduino Calculator + 🐍 Snake Game

โปรเจกต์ Arduino ที่รวม **เครื่องคิดเลข** และ **เกม Snake** ไว้ในอุปกรณ์เดียว โดยใช้ LCD I2C ขนาด 16x2 และ Keypad 4x4

## ✨ ความสามารถ

* 🧮 เครื่องคิดเลขพื้นฐาน

  * บวก `+`
  * ลบ `-`
  * คูณ `×`
  * หาร `÷`
* 🐍 เกม Snake
* 🎮 ควบคุม Snake ด้วย Keypad
* 📺 แสดงผลผ่าน LCD 16x2
* 🔄 สลับระหว่าง Calculator และ Snake
* 🏆 ระบบคะแนนในเกม Snake
* ⚡ เกมจะเร็วขึ้นเมื่อกินอาหาร
* 🚫 ป้องกันการหารด้วยศูนย์

# 🔧 อุปกรณ์ที่ใช้

| อุปกรณ์            |      จำนวน |
| ------------------ | ---------: |
| Arduino Uno / Nano |          1 |
| LCD I2C 16x2       |          1 |
| Keypad 4x4         |          1 |
| สาย Jumper         | ตามต้องการ |

# 🔌 การต่อสาย

## LCD I2C

| LCD I2C | Arduino Uno |
| ------- | ----------- |
| GND     | GND         |
| VCC     | 5V          |
| SDA     | A4          |
| SCL     | A5          |

> ถ้าใช้ Arduino รุ่นอื่น ตำแหน่ง SDA/SCL อาจแตกต่างกัน

## Keypad 4x4

| Keypad | Arduino |
| ------ | ------: |
| Row 1  |      D2 |
| Row 2  |      D3 |
| Row 3  |      D4 |
| Row 4  |      D5 |
| Col 1  |      D6 |
| Col 2  |      D7 |
| Col 3  |      D8 |
| Col 4  |      D9 |

# 📚 Library ที่ต้องติดตั้ง

โปรเจกต์นี้ใช้ Library:

```text
Wire
LiquidCrystal_I2C
Keypad
```

`Wire` เป็น Library ที่มากับ Arduino IDE อยู่แล้ว

ส่วน `LiquidCrystal_I2C` และ `Keypad` สามารถติดตั้งผ่าน:

```text
Arduino IDE
→ Sketch
→ Include Library
→ Manage Libraries
```

แล้วค้นหา:

```text
LiquidCrystal I2C
```

และ

```text
Keypad
```

# 🧮 วิธีใช้งานเครื่องคิดเลข

เมื่อเปิด Arduino ขึ้นมา ระบบจะเริ่มต้นที่โหมด Calculator

## ปุ่มตัวเลข

```text
1 2 3
4 5 6
7 8 9
  0
```

ใช้สำหรับป้อนตัวเลข

## ปุ่มเครื่องหมาย

| ปุ่ม | การทำงาน   |
| ---- | ---------- |
| A    | + บวก      |
| B    | - ลบ       |
| C    | × คูณ      |
| D    | ÷ หาร      |
| #    | คำนวณ      |
| *    | เข้า Snake |

### ตัวอย่าง

ต้องการคำนวณ:

```text
10 + 20
```

ให้กด:

```text
1 → 0 → A → 2 → 0 → #
```

ผลลัพธ์:

```text
Answer:
30
```

# 🐍 วิธีเล่น Snake

จากหน้า Calculator ให้กด:

```text
*
```

เพื่อเข้าสู่เกม Snake

## 🎮 การควบคุม

| ปุ่ม | ทิศทาง  |
| ---- | ------- |
| 2    | ⬆️ ขึ้น |
| 8    | ⬇️ ลง   |
| 4    | ⬅️ ซ้าย |
| 6    | ➡️ ขวา  |

งูจะเคลื่อนที่ไปเรื่อย ๆ ตามทิศทางที่เลือก

# 🍎 การกินอาหาร

เมื่อหัวงูเคลื่อนที่ไปโดนอาหาร:

```text
🍎
```

ระบบจะ:

* เพิ่มความยาวงู
* เพิ่มคะแนน `+10`
* สร้างอาหารตำแหน่งใหม่
* เพิ่มความเร็วของเกม

# 💀 Game Over

เกมจะจบเมื่อหัวงู:

* ชนขอบ LCD
* ชนตัวเอง

หน้าจอจะแสดง:

```text
GAME OVER

# Restart
```

กด:

```text
#
```

เพื่อเริ่มเกมใหม่

# ⚠️ ข้อควรระวัง

LCD 16x2 มีพื้นที่เพียง:

```text
16 × 2
```

หรือทั้งหมด **32 ช่อง**

ดังนั้นเกม Snake จะมีพื้นที่เล่นค่อนข้างจำกัด

นอกจากนี้การหารในโปรแกรมเป็นการหารจำนวนเต็ม เช่น:

```text
5 / 2
```

จะได้:

```text
2
```

ไม่ใช่ `2.5`

# 🚀 วิธีอัปโหลดโปรแกรม

1. เปิด **Arduino IDE**
2. เปิดไฟล์ `CalculatorSnake.ino`
3. ติดตั้ง Library ที่จำเป็น
4. เลือกบอร์ด Arduino ที่ใช้งาน
5. เลือก COM Port
6. กด **Verify** เพื่อ Compile
7. ถ้าไม่มี Error ให้กด **Upload**
8. ต่อ LCD และ Keypad ตามผังวงจร
9. เริ่มใช้งานได้เลย

---

# 🛠️ หาก LCD ไม่แสดงผล

โปรแกรมนี้กำหนด Address LCD เป็น:

```cpp
LiquidCrystal_I2C lcd(0x27, 16, 2);
```

LCD บางรุ่นอาจใช้ Address:

```text
0x3F
```

ถ้า `0x27` ไม่ทำงาน ให้ลองเปลี่ยนเป็น:

```cpp
LiquidCrystal_I2C lcd(0x3F, 16, 2);
```
